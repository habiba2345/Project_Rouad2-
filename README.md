# 🌿 موقع رواد البيئة

موقع تعليمي عن الفرز من المنبع، مبني بـ HTML/CSS/JS للفرونت إند، وباك إند بسيط بـ Node.js + Express لحفظ رسائل صفحة "اتواصل معانا" في ملف إكسل (بدون قاعدة بيانات).

## هيكل المشروع

```
rowad-el-beea/
├── server.js              ← السيرفر (Express)
├── package.json
├── public/                ← الفرونت إند بالكامل
│   ├── index.html          الصفحة الرئيسية
│   ├── about.html          اعرفنا
│   ├── learn.html          اتعلم الفرز (تفاعلي بالكامل)
│   ├── contact.html        اتواصل معانا
│   ├── css/style.css
│   └── js/
│       ├── data.js         بيانات الفرز المشتركة
│       ├── learn.js        منطق صفحة التعلم (كويز، سحب وإفلات، تحدي 7 أيام...)
│       └── contact.js      إرسال نموذج التواصل للباك إند
└── data/
    └── contacts.xlsx        ← يُنشأ تلقائيًا، وفيه كل رسائل التواصل
```

## طريقة التشغيل

1. تأكد إن عندك [Node.js](https://nodejs.org) متثبت (نسخة 18 أو أحدث يفضّل).
2. افتح Terminal داخل مجلد المشروع، ونفّذ:

```bash
npm install
npm start
```

3. افتح المتصفح على:

```
http://localhost:3000
```

## صفحة "اتواصل معانا"

- المستخدم بيدخل: الاسم، السن، العنوان بالتفصيل، ورسالة اختيارية.
- البيانات بتتبعت لـ `POST /api/contact`.
- الباك إند بيتحقق من البيانات المطلوبة (الاسم، السن، العنوان)، وبعدين بيضيف صف جديد في `data/contacts.xlsx` (بيتعمل تلقائيًا لو مش موجود).
- تقدر تفتح الملف بأي وقت بـ Excel أو Google Sheets عشان تشوف كل الرسائل.

## صفحة "اتعلم الفرز"

قسم تفاعلي شامل يغطي:
- شرح الفرز من المنبع وأهميته.
- بطاقات أنواع المخلفات الستة (عضوي، بلاستيك، ورق وكرتون، زجاج، معادن، غير قابل للتدوير).
- أداة "المخلف ده يتحط فين؟" (بحث تفاعلي).
- لعبة سحب وإفلات لمطابقة المخلفات بحاوياتها الصحيحة.
- خطوات عملية لبدء الفرز في البيت.
- قسم الأخطاء الشائعة (❌/✅).
- رحلة المخلفات بعد الفرز (رسم بصري).
- قسم العضوي والكومبوست.
- جدول "دليل سريع".
- كويز تفاعلي من 8 أسئلة صح/غلط، وفي النهاية Badge "🌱 رائد بيئي مبتدئ".
- تحدي 7 أيام مع Progress Bar (التقدم بيتخزن في المتصفح محليًا).
- نصيحة يومية بتتغيّر تلقائيًا.
- مربع "اسأل رواد البيئة" لأي مخلف مش متأكد منه المستخدم.

> ملاحظة: أي معلومة تعتمد على نظام الجمع أو إعادة التدوير المحلي (زي أماكن التسليم) موضّح في الموقع إنها بتختلف حسب المنطقة، ومفيش أي معلومة مُختلَقة.

## تخصيص البيانات

- عايز تضيف أو تعدّل أنواع مخلفات أو أسئلة كويز أو نصائح؟ كل ده موجود في ملف واحد:
  `public/js/data.js`
- عايز تغيّر الألوان أو الخطوط؟ كل المتغيرات في أول ملف
  `public/css/style.css` (داخل `:root`).
